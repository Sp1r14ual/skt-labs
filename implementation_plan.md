# Реализация обратной задачи магниторазведки с использованием искусственных нейронных сетей (ИНС) и GUI

## Описание задачи
В рамках выполнения лабораторной работы по курсу «Современные Компьютерные Технологии» (ФПМИ НГТУ, гр. ПММ-51, вариант 5):
1. Разработать алгоритм решения прямой задачи магниторазведки (дипольное/ячеистое аналитическое решение для компонент $B_x$, $B_z$).
2. Разработать препроцессор входных данных: сглаживание и интерполяция зарегистрированных сигналов при помощи кубического сглаживающего сплайна (эрмитов базис) для обработки зашумленных данных и нерегулярных профилей приемников (раздел 3.1 пособия НГТУ 2021).
3. Создать генератор синтетических геологических моделей среды и датасета ($\ge 2000$ моделей) сбалансированным методом блочных разрезов (способ 2 из пособия) и методом изолированных аномалий.
4. Разработать и обучить полносвязную нейронную сеть (PyTorch MLP) для ячеистой инверсии (восстановление распределения намагниченности $\lambda_i$).
5. Реализовать валидацию и тестирование:
   - на тестовой выборке датасета (10%);
   - на тестовой модели из первой лабораторной работы (прямоугольное тело);
   - на сложных моделях (наклонная аномалия, два тела, зашумленный сигнал);
   - сравнить качество с классическим методом инверсии с $\gamma$-регуляризацией из прошлой работы.
6. Разработать интерактивный графический интерфейс (GUI) на базе `tkinter` + `matplotlib`, позволяющий визуализировать модели, сигналы, обучать нейросеть с живыми графиками loss, проводить инверсию и сравнивать результаты.
7. Подготовить автоматические сценарии экспериментов и сформировать отчетные материалы.

## Предлагаемые изменения и модули

### 1. [NEW] `forward_problem.py`
- Класс `MagneticSurvey2D`:
  - Параметризация расчетной области: $N_x \times N_z$ ячеек размером $dx \times dz$, толщина $dy$.
  - Центры ячеек $(x_k, z_k)$, приемники $(x_r, z_r)$ вдоль профиля.
  - Аналитический расчет коэффициентов матрицы прямого оператора $L$ по формулам (7)–(9) пособия:
    $$B_{x} = \sum_k L_{xx}^{(k, r)} p_{xk} + L_{xz}^{(k, r)} p_{zk}$$
    $$B_{z} = \sum_k L_{zx}^{(k, r)} p_{xk} + L_{zz}^{(k, r)} p_{zk}$$
    где $p = \lambda_k p_0$, $p_0 = (1, 0, 0)^T$ (или $(0, 0, 1)^T$).
  - Быстрый расчет сигналов через матричное умножение: $g = L \lambda$.

### 2. [NEW] `preprocessor.py`
- Реализация алгоритма кубического эрмитова сглаживающего сплайна (формулы 53–59 пособия):
  - Построение матрицы базисных функций $\Psi$ и матрицы регуляризации производных.
  - Решение СЛАУ $A q = b$ для нахождения сплайна $\hat{B}(x)$.
  - Интерполяция сигнала с произвольных положений $x_j$ на фиксированные узлы приемников $\tilde{x}_p$.
  - Функция фильтрации шума.

### 3. [NEW] `dataset.py`
- Класс `DatasetGenerator`:
  - Реализация способа 2 (алгоритм случайных вертикальных разрезов $M_x$ и горизонтальных $M_z^i$ для обеспечения равномерной плотности покрытия по всей сетке, рис. 36–37 пособия).
  - Реализация способа 1 (случайные прямоугольные и наклонные блоки, одиночные и кратные аномалии).
  - Включение тестовых моделей из первой работы (прямоугольная аномалия $ix \in [8, 12), iz \in [3, 6)$).
  - Добавление случайного гауссова шума (1%, 5%, 10%).
  - Быстрый векторизованный расчет сигналов через матрицу $L$.
  - Сохранение/загрузка датасета (`dataset.npz`).

### 4. [NEW] `neural_net.py` и `train.py`
- Модель `MagneticInversionNet(nn.Module)`:
  - Вход: $N_{receivers}$ значений индукции (например, 40 или 100).
  - Скрытые слои: Linear(in, 400) -> BatchNorm1d -> ReLU -> Dropout(0.15) -> Linear(400, 400) -> ReLU -> Linear(400, n_cells).
  - Выход: вектор $\lambda \in [0, 1]$ (с Sigmoid или неотрицательным ReLU).
- Тренер `Trainer`:
  - Функция потерь: MSELoss (формула 61).
  - Метрика: MAE (формула 62).
  - Оптимизатор: Adam с CosineAnnealingLR / ReduceLROnPlateau.
  - Разделение выборки 90% train / 10% val.
  - EarlyStopping и сохранение лучших весов (`best_model.pt`).

### 5. [NEW] `classical_inversion.py`
- Воспроизведение решения из первой работы:
  - Построение матрицы $C$ регуляризации по $\gamma$ на 4-связной сетке соседей:
    $C_{ij} = -(\gamma_i + \gamma_j)$, $C_{ii} = \sum_m (\gamma_i + \gamma_m)$.
  - Решение регуляризованной СЛАУ: $(L^T L + C) \lambda = L^T g_{obs}$.
  - Итеративное обновление $\gamma$ или подбор параметра Тихонова для наглядного сравнения.

### 6. [NEW] `gui.py`
- Графический интерфейс на Tkinter + Matplotlib Canvas:
  - **Панель управления**:
    - Выбор предустановленных моделей: «Тестовая модель из Лаб. 1», «Наклонный пласт», «Два объекта», «Случайная модель».
    - Настройка уровня шума и количества приемников.
    - Кнопки: «Рассчитать поле», «Сгладить препроцессором», «Решить ИНС», «Решить регуляризацией», «Обучить нейросеть».
  - **Область визуализации** (4 интерактивных графика):
    1. Истинная модель среды (2D heatmap).
    2. Восстановленная модель нейросетью (2D heatmap) с метриками ошибки.
    3. Восстановленная модель классическим методом ($\gamma$-регуляризация).
    4. График сигналов на профиле: $B_{true}$, $B_{obs}$ (с шумом/нерегулярным), $B_{preprocessed}$, $B_{calc}^{NN}$, $B_{calc}^{reg}$ + график невязки.
  - Вкладка/диалог обучения нейросети с живым графиком кривых обучения (Train Loss / Val Loss).

### 7. [NEW] `run_experiments.py` и `REPORT.md`
- Запуск серии экспериментов, сохранение графиков в высоком разрешении (PNG) для отчета:
  - Сравнение истинной модели и предсказания ИНС на тесте из Лаб. 1.
  - Оценка устойчивости к шуму (1%, 5%, 10%).
  - Оценка работы препроцессора при неравномерных приемниках.
  - Сравнение с $\gamma$-регуляризацией.
  - График обучения (Train Loss / Val Loss).
- Генерация файла `REPORT.md` с описанием теории, постановок задач, результатов и выводов.
