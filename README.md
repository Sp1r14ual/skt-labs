# Решение обратной задачи магниторазведки с использованием ИНС

Программный комплекс для решения двумерной обратной задачи магниторазведки (ячеистая инверсия) с применением аппарата искусственных нейронных сетей (ИНС), сглаживающего сплайна Эрмита в качестве препроцессора и сопоставлением с классическим методом $\gamma$-регуляризации.

---

## Быстрый старт

### 1. Требования и окружение
Для работы требуется Python 3.10–3.14 и библиотеки:
```bash
pip install -r requirements.txt
```

### 2. Запуск программы
Все основные действия вызываются через единую точку входа `main.py`:

```bash
# 1. Запуск интерактивного графического интерфейса (GUI):
python main.py
# или:
python main.py --gui

# 2. Автоматический запуск серии экспериментов и сохранение графиков в results/:
python main.py --exp

# 3. Запуск генерации датасета и переобучения нейросети:
python main.py --train

# 4. Проверка работоспособности модулей:
python main.py --test
```

## Руководство по работе с графическим интерфейсом (GUI)

Интерфейс разделен на панель управления слева и область визуализации справа (4 интерактивных графика):

```
+------------------------------------+------------------------------------+
|  1. Истинная модель среды          |  2. Искусственная нейронная сеть   |
|  (интерактивный клик мышью)        |  (быстрое предсказание ~1 мс)      |
+------------------------------------+------------------------------------+
|  3. Классический алгоритм          |  4. Графики сигналов B_x           |
|  (решение СЛАУ с регуляризацией)   |  (наблюденный, сплайн, отклики)    |
+------------------------------------+------------------------------------+
```

### Основные элементы управления:
1. **Геологическая модель среды**:
   - Выпадающий список предустановленных моделей: *Тестовая модель*, *Аномалия среднего размера*, *Наклонный пласт / разлом*, *Два разделенных тела*, *Два перекрывающихся тела*, *Случайная блочная модель*.
   - **Интерактивное рисование мышью**: щелкните левой кнопкой мыши по ячейкам верхнего левого графика (*Истинная модель*), чтобы вручную включать/выключать аномалии в любых ячейках среды. Поле пересчитывается автоматически в реальном времени!
2. **Синтетический датасет**:
   - **Индикатор статуса**: отображает имя файла датасета и количество моделей в выборках Train (90%) и Val/Test (10%).
   - Кнопка **«Пример из Val (тест)»**: мгновенно подгружает случайный образец из тестовой выборки для проверки качества ИНС на неизвестных данных.
   - Поле **«Сэмпл №»** и кнопка **«Загрузить»**: выбор конкретного тестового образца по его номеру.
   - Кнопка **«Загрузить .npz»**: выбор существующего файла датасета через проводник.
   - Кнопка **«Генератор»**: диалоговое окно для генерации нового сбалансированного датасета с заданным числом моделей, долями Способов 1 и 2 и уровнем шума.
3. **Параметры измерений**:
   - Ползунок **Случайный шум (0–20%)** — моделирует погрешность полевых измерений.
   - Переключатель **Сетка приемников**:
     - *Регулярная сетка* (40 приемников с равномерным шагом);
     - *Нерегулярный профиль* (30 приемников со случайными сгущениями и разрядками).
4. **Препроцессор (Сплайн Эрмита)**:
   - Кнопка **«Применить сглаживающий сплайн»** — аппроксимирует дискретные зашумленные замеры непрерывным кубическим эрмитовым сплайном с регуляризацией первой производной и пересчитывает значения в стандартные узлы нейросети.
5. **Решение обратной задачи**:
   - **Решить с помощью ИНС** — мгновенное восстановление ячеистой структуры моделью PyTorch.
   - **Решить классическим методом** — расчет СЛАУ с заданными параметрами $\gamma$ и $\alpha$.
   - **Сравнить оба метода** — одновременный запуск и расчет сравнительных метрик (MAE, MSE, относительная невязка поля $R_{sq}$, норма невязки $\|e\|$).
6. **Обучение нейросети**:
   - Кнопка **«Открыть окно обучения ИНС»** открывает окно обучения: возможность обучать на уже загруженном датасете (без повторной долгой генерации) или сгенерировать новый с отслеживанием живых кривых функции потерь (Train Loss / Val Loss) в реальном времени.
7. **Метрики и экспорт**:
   - Кнопка **«Экспорт результатов в CSV»** сохраняет файлы `*_signals.csv` (наблюденные, сглаженные и рассчитанные профили полей) и `*_model.csv` (координаты ячеек, истинные и восстановленные значения намагниченности) для дальнейшего анализа.

## Архитектура проекта

- **`main.py`** — единая консольная точка входа.
- **`gui.py`** — реализация графического интерфейса приложения.
- **`forward_problem.py`** — класс `MagneticSurvey2D`: дипольное приближение для компонент индукции $B_x, B_z$, матричный оператор $L$, добавление шума.
- **`preprocessor.py`** — класс `HermiteSmoothingSpline` и `SignalPreprocessor`: сглаживание и интерполяция геофизических профилей.
- **`dataset.py`** — класс `DatasetGenerator`: генерация сбалансированных блочных моделей (Способ 2) и наборов изолированных тел.
- **`neural_net.py`** — класс `MagneticInversionNet`: полносвязная нейросеть (MLP) с BatchNorm, Dropout и ReLU/Sigmoid.
- **`train.py`** — модуль адаптивного обучения с планировщиком скорости обучения, метриками MSE/MAE и EarlyStopping.
- **`classical_inversion.py`** — класс `ClassicalInversion`: решение обратной задачи методом наименьших квадратов с $\alpha$ и $\gamma$-регуляризацией на 4-связной сетке соседей.
- **`run_experiments.py`** — автоматический прогон всех контрольных тестов с сохранением иллюстраций в папку `results/`.
