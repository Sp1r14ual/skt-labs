## 2. Теоретическая часть

### 2.1. Прямая задача гравиразведки
Гравитационное поле описывается уравнением:
$$\operatorname{div} \vec{G} = \rho$$
где $\rho$ — избыточная плотность среды, $\vec{G}$ — вектор силы тяжести.

В произвольной точке $M(x, y, z)$ поле точечного источника единичной плотности, сосредоточенного в ячейке $\Omega_k$, определяется соотношением:
$$\vec{G}^k = \operatorname{mes}(\Omega_k) \frac{1}{4\pi r^3} (\tilde{x}\vec{e}_x + \tilde{y}\vec{e}_y + \tilde{z}\vec{e}_z)$$
где $r = \sqrt{\tilde{x}^2 + \tilde{y}^2 + \tilde{z}^2}$, $(\tilde{x}, \tilde{y}, \tilde{z})$ — координаты точки измерения относительно центра ячейки.

При измерении вертикальной компоненты приращения силы тяжести $\Delta g = G_z$ вдоль профиля на дневной поверхности поле представляется в виде линейной комбинации:
$$\Delta \tilde{g}_i = \sum_{k=1}^{K} L_{ik} \rho_k \quad \Longleftrightarrow \quad \tilde{\mathbf{g}} = \mathbf{L} \boldsymbol{\rho}$$
где $\mathbf{L} \in \mathbb{R}^{N_{rec} \times N_{cells}}$ — матрица прямого гравиметрического оператора.

### 2.2. Классическая обратная задача с регуляризацией
Поиск вектора плотности $\boldsymbol{\rho}$ при минимизации функционала Тихонова с регуляризацией по $\gamma$ (сглаживающий оператор лапласианного типа):
$$\Phi^\gamma(\boldsymbol{\rho}) = \|\mathbf{g}_{obs} - \mathbf{L}\boldsymbol{\rho}\|^2 + \gamma \sum_{k=1}^K \sum_{m \in \text{Nei}(k)} (\rho_k - \rho_m)^2$$
Минимизация функционала сводится к решению СЛАУ:
$$(\mathbf{L}^T \mathbf{L} + \mathbf{C}) \boldsymbol{\rho} = \mathbf{L}^T \mathbf{g}_{obs}$$
где $\mathbf{C}$ — разреженная матрица регуляризации по смежным ячейкам.

### 2.3. Постановка задачи машинного обучения
Нейросеть рассматривается как нелинейный оператор инверсии $\mathcal{F}_{\mathbf{W}}: \mathbb{R}^{N_{rec}} \to \mathbb{R}^{N_{cells}}$, восстанавливающий вектор параметров среды напрямую по замерам гравитационного поля:
$$\hat{\boldsymbol{\rho}} = \mathcal{F}_{\mathbf{W}}(\mathbf{g}_{obs})$$

#### Архитектура сети:
Использована полносвязная глубокая архитектура (MLP):
1. **Входной слой:** 100 нейронов (по числу приемников на профиле).
2. **Скрытый слой 1:** 512 нейронов + батч-нормализация (`BatchNorm1d`) + активация `ReLU` + `Dropout(0.1)`.
3. **Скрытый слой 2:** 1024 нейрона + батч-нормализация (`BatchNorm1d`) + активация `ReLU` + `Dropout(0.1)`.
4. **Выходной слой:** 800 нейронов (сетка $40 \times 20$ ячеек) + активация `ReLU`, гарантирующая физическую неотрицательность аномальной плотности ($\rho \ge 0$).

#### Функция потерь и метрика:
В соответствии с учебным пособием обучение проводилось по функции среднеквадратичной ошибки (MSE):
$$\text{MSE} = \frac{1}{N_{cells}} \sum_{k=1}^{N_{cells}} (\hat{\rho}_k - \rho_k)^2$$
А валидация качества — по средней абсолютной ошибке (MAE):
$$\text{MAE} = \frac{1}{N_{cells}} \sum_{k=1}^{N_{cells}} |\hat{\rho}_k - \rho_k|$$

## 3. Формирование обучающего датасета

Для обучения сети сгенерирован синтетический датасет из **3000 разнородных моделей среды**:
- Расчетная область: $N_x = 40$, $N_z = 20$ ячеек ($dx=1.0$, $dz=1.0$, всего 800 ячеек).
- Профиль приема: 100 приемников, равномерно распределенных по $X \in [0, 40]$ на высоте $Z = 1.0$.
- В каждую модель случайным образом помещалось от 1 до 3 аномальных тел различной геометрии:
  - прямоугольные блоки случайной ширины (2–8 ячеек) и мощности (2–5 ячеек);
  - наклонные пластовые залежи и дайки со смещением;
  - ступенчатые тела с переменным заглублением.
- Плотность аномалий варьировалась в пределах $\rho \in [0.6, 1.5]$.
- Для каждого разреза решена прямая задача с наложением аддитивного случайного гауссова шума с уровнем $1\%$ ($\sigma = 0.01 \max |g|$).
- Выборка разбита на обучающую (90%, 2700 моделей) и валидационную (10%, 300 моделей).

## 5. Исследование качества решения обратной задачи

Тестирование разработанной нейросети проведено в сравнении с классической Тихоновской инверсией ($\gamma = 0.1$) на контрольных геометриях из учебного пособия:

### Сводная таблица сравнительных характеристик:
| Параметр | Классическая инверсия ($\gamma$-регуляризация) | Обученная нейросеть (PyTorch) |
| :--- | :--- | :--- |
| **Время вычисления инверсии** | $\approx 195 - 220$ мс | **$\approx 1.5 - 2.0$ мс (ускорение в ~110-130 раз)** |
| **Невязка гравитационного поля** | $0.081 - 0.088$ | $0.34 - 0.36$ |
| **MSE ошибки восстановления плотности** | $0.0138$ | **$0.0071$ (ошибка формы ниже в 1.95 раза)** |
| **Характер восстановления** | Сильное вертикальное размазывание вглубь | Локализованные контуры, четкая верхняя кромка |

### Анализ моделей среды:
1. **Стандартная аномалия (ЛР №1):** Нейросеть безошибочно определяет латеральное положение объекта ($X \in [8, 12]$) и его глубину залегания без паразитных «хвостов» проводимости/плотности на больших глубинах.
2. **Аномалия среднего размера:** Восстанавливается как единое связное тело с правильным центром масс.
3. **Наклонная аномалия / дайка:** Нейросеть надежно восстанавливает верхнюю кромку наклонного пласта, что согласуется с результатами пособия.
4. **Сложная форма / разлом:** Выявляется ступенчатый характер залегания.
5. **Два объекта по латерали:** Четко разрешаются оба тела без слияния в один фиктивный объект.
6. **Перекрывающие объекты (экранирование):** Верхний пласт экранирует часть поля, однако нейросеть фиксирует наличие глубокого тела, в то время как классический метод дает монотонно затухающее пятно.
7. **Поверхностная аномалия:** Дает высокоамплитудный узкий пик, идеально восстанавливаемый сетью.
8. **Глубоколежащий объект:** Глубокая аномалия создает гладкий колоколообразный отклик; нейросеть локализует центр тяжести аномалии на нужной глубине.

Разработано самостоятельное кроссплатформенное приложение с графическим интерфейсом на базе библиотеки `CustomTkinter` со встроенным холстом интерактивной визуализации `Matplotlib`.

### Структура проекта:
- `gravity_core.py` — математический модуль решения прямой задачи, СЛАУ регуляризации и генерации синтетических геометрий.
- `model.py` — описание PyTorch-архитектуры нейросети `GravityNN`.
- `train_nn.py` — консольный скрипт для переобучения сети с сохранением весов `gravity_nn.pth`.
- `test_nn.py` — консольный скрипт тестирования и экспорта сводных графиков.
- `main.py` — графическое приложение пре- и постпроцессора.
- `requirements.txt` — список внешних зависимостей.

### Функционал графического интерфейса:
1. **Панель выбора геометрий:** выпадающий список всех 10 типов моделей (включая процедурные случайные генерации) с кнопкой мгновенной регенерации.
2. **Управление шумом:** ползунок регулировки уровня инструментального шума измерений (от 0% до 5%).
3. **Параметры классического решателя:** поле ввода коэффициента $\gamma$-регуляризации.
4. **Вычислительный блок:** раздельный или комплексный запуск классического метода и нейросетевого вывода.
5. **Сводная панель метрик:** расчет времени вычислений (мс), невязки поля и MSE плотности, отображение коэффициента ускорения.
6. **Интерактивные графики (4 панели):**
   - профиль наблюдаемого и рассчитанных полей $\Delta g$;
   - 2D-разрез истинной модели среды;
   - 2D-разрез классической инверсии;
   - 2D-разрез нейросетевой реконструкции.
7. **Корректное завершение:** перехват события `WM_DELETE_WINDOW` для мгновенного освобождения ресурсов при закрытии окна.

## 8. Исходный код программы

### 8.1. Файл `model.py` (Архитектура сети)
```python
import torch
import torch.nn as nn

class GravityNN(nn.Module):
    def __init__(self, in_features=100, out_features=800, hidden_dims=(512, 1024), dropout=0.1):
        super(GravityNN, self).__init__()
        layers = []
        prev_dim = in_features
        for h_dim in hidden_dims:
            layers.append(nn.Linear(prev_dim, h_dim))
            layers.append(nn.BatchNorm1d(h_dim))
            layers.append(nn.ReLU())
            if dropout > 0:
                layers.append(nn.Dropout(dropout))
            prev_dim = h_dim
        layers.append(nn.Linear(prev_dim, out_features))
        layers.append(nn.ReLU())
        self.network = nn.Sequential(*layers)

    def forward(self, x):
        return self.network(x)
```

### 8.2. Файл `gravity_core.py` (Фрагмент решения прямой и обратной задачи)
```python
import numpy as np

class GravitySolver:
    def __init__(self, nx=40, nz=20, dx=1.0, dz=1.0, n_receivers=100, receiver_z=1.0):
        self.nx, self.nz = nx, nz
        self.dx, self.dz = dx, dz
        self.n_cells = nx * nz
        self.n_receivers = n_receivers
        self.cells = np.array([(ix * dx, -iz * dz) for ix in range(nx) for iz in range(nz)])
        self.receivers = np.column_stack([np.linspace(0, nx * dx, n_receivers), np.full(n_receivers, receiver_z)])
        self.L = self._build_L()
        self.neighbors = self._get_neighbors()

    def _build_L(self):
        dx = self.receivers[:, 0:1] - self.cells[:, 0:1].T
        dz = self.receivers[:, 1:2] - self.cells[:, 1:2].T
        r = np.sqrt(dx**2 + dz**2) + 1e-8
        return dz / (r**3)

    def forward(self, rho):
        return self.L @ rho

    def solve_classical_inverse(self, g_obs, gamma=1e-1):
        C = self.build_C(gamma)
        A = self.L.T @ self.L
        b = self.L.T @ g_obs
        return np.linalg.solve(A + C, b)
```
